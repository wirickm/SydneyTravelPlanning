## Deleting this repo

This repo is now just a pointer to wirickm.github.io and can be removed.

**What gets deleted:** only `wirickm/SydneyTravelPlanning` (its README, history, issues and PRs). Nothing in wirickm.github.io or the live map is affected.

**How (repo owner only):**

1. Open <https://github.com/wirickm/SydneyTravelPlanning/settings>
2. Scroll to **Danger Zone** at the bottom.
3. Pick one:
   - **Archive this repository** - read-only, reversible. Safer choice.
   - **Delete this repository** - permanent. Type `wirickm/SydneyTravelPlanning` to confirm.
