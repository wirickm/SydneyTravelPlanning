# SydneyTravelPlanning

A Sydney travel planning map focused on New Year's Eve (NYE) points of interest, generated with [Folium](https://python-visualization.github.io/folium/) (a Python library built on [Leaflet.js](https://leafletjs.com/)).

## What's in this repo

- **** — An interactive map of points of interest in and around Sydney, annotated with distances from Sydney Airport (SYD). Open it in any modern browser to explore locations, filter by category, and view distance/travel-time details.

> **Note:** The Python generation script that produces this map is not stored in this repository. Only the rendered HTML output is committed here.

## Viewing the map

The map is hosted via GitHub Pages:  
**<https://wirickm.github.io/SydneyTravelPlanning/>**

You can also download  and open it locally in any modern browser — no server required.
